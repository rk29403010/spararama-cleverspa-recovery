    V2 Wi-Fi setup

    Reconnect the blue-display panel

    Hold the physical Wi-Fi button and release it at the first beep. The Wi-Fi indicator may change or flash while the panel enters setup mode.

    Use a 2.4 GHz Wi-Fi network. Credentials go only to your local Spararama server and are kept only when you explicitly choose secure saving below. For safety, setup must be run from the computer hosting Spararama.
