## Espressif ESPTouch

The Wi-Fi provisioning encoder in `src/provisioning/esptouch.js` is a clean
JavaScript implementation of the ESPTouch v1 protocol described by Espressif's
`EsptouchForAndroid` project. It is intended only for communicating with the
ESP8266-family module selected by the archived CleverLink application. The
multicast packet scheduling and BSSID-bearing datum layout match the ESPTouch
copy embedded in CleverLink 2.12.
